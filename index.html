    Hax — Heterogeneity Analysis for CryoEM¶

    A suite of GPU-accelerated tools to study conformational heterogeneity in Cryo-EM data. Estimate the continuous motions of your macromolecules, build and merge conformational landscapes, and reconstruct motion-corrected volumes — all from a single command line.

    Get Started Browse Programs View Workflows

    What is Hax?¶

    When a protein or molecular machine is imaged with Cryo-EM, every particle is a snapshot of the molecule frozen in a slightly different shape (or conformation). Classical reconstruction averages these snapshots into a single rigid map — and in doing so, it blurs away the very motions that make the molecule biologically interesting.

    Hax is a collection of tools designed to recover that lost information. It uses modern neural networks (built on JAX + Flax) to learn how your molecule moves, to place every particle on a map of conformations (a conformational landscape), and to turn that landscape back into 3D structures you can inspect.

    You do not need to be a machine-learning expert to use Hax. Every tool is a single command, the defaults are sensible, and this documentation explains each option in plain language.

    New to conformational heterogeneity?

    Start with the Core Concepts page. It introduces the handful of ideas — latent spaces, the CTF, metadata files, training modes — that show up across every Hax program.

    What can it do?¶

    •   Analyze motions

      Recover continuous conformational changes with HetSIREN, Zernike3Deep and ReconSIREN.

      Heterogeneity analysis

    •   Merge landscapes

      Reconcile results from several methods into a single consensus space with FlexConsensus.

      FlexConsensus

    •   Explore interactively

      Navigate your landscape and generate volumes in real time with the Annotate Space viewer.

      Annotate Space

    •   Reconstruct without blur

      Build motion-corrected volumes that remove the smearing caused by flexibility, with MoDART.

      MoDART

    Install in one line¶

    pip install hax-em[cuda12]

    pip install hax-em[cuda13]

    CUDA itself is installed for you — you only need a recent NVIDIA driver (≥ 525). See the full installation guide for the recommended Conda setup.

    Two ways to run Hax

    Use the command line, or run every program from your browser with the optional Hax GUI. After installing, you can verify everything works with the built-in test suite.

    A typical session¶

    # 1. See what is available
hax_project_manager -h

# 2. Learn the conformational landscape of your particles
hax_project_manager --gpu 0 zernike3deep \
    --md particles.xmd --vol reference.mrc --sr 1.5 \
    --ctf_type apply --mode train --output_path results/

# 3. Explore the landscape interactively
hax_project_manager annotate_space \
    --z_space results/predicted_latents.xmd --path annotation/

    Ready to dive in? Head to Getting Started, or jump straight to the Programs overview.

    How to cite Hax¶

    If Hax is useful in your research, please cite the relevant method(s). The full reference list — Zernike3D, HetSIREN, ZART/MoDART and FlexConsensus — is on the Contact & Support page.
