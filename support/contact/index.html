    Contact & Support¶

    Hax is developed in the open. Whether you hit a bug, have a question, or want to suggest an improvement, we'd love to hear from you.

    Report an issue or ask a question¶

    The best place for bug reports, questions and feature requests is the project's GitHub issue tracker:

    Open an issue on GitHub Browse the repository

    Before opening a new issue, it helps to search the existing ones — your question may already be answered.

    Writing a useful bug report¶

    To help us reproduce and fix a problem quickly, please include:

    • What you ran — the full hax_project_manager … command line.
    • What happened — the full error message / traceback, copied as text.
    • What you expected to happen instead.
    • Your environment — Hax version (python -c "import hax; print(hax.__version__)"), the CUDA extra you installed (cuda12/cuda13), your GPU and NVIDIA driver version (nvidia-smi).
    • Data shape, when relevant — number of particles, box size, sampling rate.

    Check the metrics first

    If a training run behaved oddly, the curves shown by Display Metrics often reveal what went wrong (e.g. a diverging loss pointing at too high a learning rate). Attaching a screenshot can speed up diagnosis.

    Report a graphical interface (GUI) issue or improvement¶

    Problems, questions and suggestions about the Hax graphical interface belong in its own GitHub issue tracker, which is separate from the core hax-em one:

    Open an issue on GitHub Browse the repository

    As above, please search the existing issues before opening a new one — someone may have already reported the same thing.

    Writing a useful GUI report¶

    Because the interface is visual, screenshots are the single most helpful thing you can attach — both for bugs and for improvement ideas:

    • Screenshots — capture the screen showing the problem (or the part you'd like to see improved). For a bug, include the moment the error or unexpected behaviour appears; for a suggestion, mark up the screenshot to show what you have in mind. You can drag-and-drop images straight into the GitHub issue text box.
    • What you were doing — the steps that led to the issue (which panel, which buttons, which program you were launching).
    • What happened vs. what you expected to happen instead.
    • Any error text — messages shown in the interface, and anything printed in the terminal / console the GUI was started from (copied as text).
    • Your environment — the GUI version, your operating system and browser (if you use the web interface), and the Hax version (python -c "import hax; print(hax.__version__)").

    Capturing a screenshot

    On most systems: Windows — Win+Shift+S; macOS — Cmd+Shift+4; Linux — the Screenshot utility or Print. Recording a short screen capture (GIF or video) is even better when the problem only shows up while interacting with the interface.

    Tutorials¶

    To run Hax inside Scipion, see Using Hax from Scipion. Step-by-step tutorials covering the use of Hax together with Scipion are in preparation. They will be announced through the project's GitHub repository.
