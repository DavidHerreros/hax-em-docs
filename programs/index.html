    Programs Overview¶

    Hax bundles sixteen command-line programs, all launched through hax_project_manager (see The Command Line). They fall into seven families, listed below in roughly the order you would use them in a project.

    Every program page follows the same layout

    What it does → reference paper → when to use it → parameters → example commands → outputs → tips. If a term is unfamiliar, check Core Concepts first.

    Preprocessing¶

    Optional, but often the first thing you run: shrink the box to trade resolution for speed and VRAM, and correct the CTF once instead of every epoch.

    •   Preprocess Particles

      Resize/crop a particle stack and optionally Wiener- or phase-flip-correct it.

      Preprocess Particles

    •   Preprocess Volumes

      Resize/crop reference maps and masks to match a preprocessed particle set.

      Preprocess Volumes

    Heterogeneity analysis¶

    The core of Hax: learn how your molecule moves and place every particle on a conformational landscape.

    •   HetSIREN

      Real-space heterogeneous reconstruction, refinement and disentanglement of conformational states.

      HetSIREN

    •   Zernike3Deep

      Deep-learning estimation of continuous motions using the 3D Zernike basis.

      Zernike3Deep

    •   ReconSIREN

      Ab initio pose/shift assignment and initial volume estimation.

      ReconSIREN

    Consensus & deconvolution¶

    Combine and refine landscapes coming from one or several methods.

    •   FlexConsensus

      Merge multiple conformational landscapes into one consensus space.

      FlexConsensus

    •   Estimate Latent Covariances

      Estimate the per-particle uncertainty needed for landscape deconvolution.

      Estimate Latent Covariances

    •   Latent Space Deconvolution

      Sharpen a landscape by removing the blurring caused by estimation noise.

      Latent Space Deconvolution

    Gray-scale adjustment¶

    Match intensity levels between maps and images before further analysis.

    •   Image Gray-Scale Adjustment

      Even out the contrast of the particles against the projections of a map (closed form).

      Image Gray-Scale Adjustment

    •   Volume Gray-Scale Adjustment

      Put a map on the gray scale of a set of particles (closed form).

      Volume Gray-Scale Adjustment

    Latent post-processing¶

    Utilities to turn latent spaces into volumes or to clean them up.

    •   Decode States from Latents

      Generate 3D volumes from a trained network and a list of latent vectors.

      Decode States from Latents

    •   Filter Latents

      Remove outliers from a latent space using z-scores.

      Filter Latents

    Reconstruction¶

    •   Reconstruct Volume

      Single-pass consensus map from posed particles, FSC-denoised and gray-scale calibrated.

      Reconstruct Volume

    •   MoDART

      Least-squares reconstruction with motion-blur correction from deformation fields.

      MoDART

    Visualization¶

    •   Annotate Space

      Interactive landscape exploration with real-time volume generation.

      Annotate Space

    •   Display Metrics

      Launch a TensorBoard dashboard to monitor training metrics.

      Display Metrics
